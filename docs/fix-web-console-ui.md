# 修复记录：按 mock 重做 Web 控制台 UI

## 2026-11-19 · mock 风格重构

### 现象 / 目标

现有 Web 控制台是「顶部导航 + 表格页」结构，与用户提供的 mock（`%TEMP%\qc-mock\index.html`）差异较大。目标：

- 改为「项目栏 + 图标 Launcher → 命令页 → 日志/属性面板」的栈式布局；
- 沿用 mock 的暗色视觉与响应式行为；
- 接真实数据（命令、实例、历史、日志），保留启停、固定、历史等已有能力。

本次只改 `quickcmdhost/WebConsole.cs` 的内嵌页面（HTML/CSS/JS），HTTP 端点和宿主侧逻辑未改。

### mock 中发现并修订的缺陷

| 现象 | 原因 | 处理 |
|---|---|---|
| 项目栏永不隐藏 | mock 的 CSS 依赖 `body[data-rail]`，但脚本从未设置 | `applyWidth()` 同时设置 `data-rail` |
| 已结束状态的点不可见 | `.dot.down` 没有样式 | 补齐 `down` / `fail` 颜色 |
| 窄屏命令页按钮被裁掉 | `.app-head{overflow:hidden;flex-wrap:nowrap}` | 窄屏改为换行、操作区独占一行 |
| 窄屏顶栏溢出 | 主机信息、Ctrl+K 文案占宽 | 窄屏隐藏主机信息与快捷键文案 |
| 首屏搜索在放不下项目栏时没有替代入口 | 依赖底部屏指示器 | 指示器单屏时隐藏，多屏时保留 |
| 执行记录选中会串行 | 用行下标记录选中 | 改为「实例 ID + 启动时间」稳定 key |
| 点行内「停止/重跑」会变成选中该行 | 行点击先于按钮处理 | 按钮点击不触发行选中 |
| 新增记录后选中的是另一条 | 下标随列表前移 | 稳定 key + 找不到时回退第一条 |
| 方向键在搜索框里会切屏 | keydown 未排除输入框 | 输入框聚焦时忽略切屏快捷键 |
| 「执行历史」按钮无实现 | mock 只有按钮 | 补齐浮层表格（状态、退出码、时长、日志） |
| 实例 ID 跨宿主重启重复 | 仅用实例 ID 当 key 会撞车 | key 加启动时间前缀 |

### 实现要点

- 执行记录 = 当前实例（运行中）+ `history` 中 `event=finish` 且 short-id 匹配的记录；结束行的启动时间 = 完成时间 − 时长。
- 失败判定：退出码非 0，或状态为 `failed|max|host-unavailable`。
- 日志：`GET /api/log?key=<logPath|shortId>&tail=300`；运行中随 3 秒轮询刷新（缓存 1500ms），已结束只取一次；接近底部时自动跟随，向上滚动不打断。
- 宽屏选中命令时自动打开日志面板；没有执行记录时不打开空面板。
- 固定按钮继续调用 `/api/pin`；属性面板展示真实字段。
- 浮层「执行历史」取 `/api/state` 最近的 60 条，日志按钮在新标签页打开。
- 深链 `#<项目>/<short-id>`；`Ctrl+K` 回首页并聚焦搜索；`Esc` 浮层 → 面板 → 命令页逐层回退。

## 2026-11-19 · 补充：直接输入即搜索

### 现象 / 目标

重做后只剩顶栏搜索按钮和「全部」屏的搜索框，旧版「页面任意位置直接输入就能搜索」丢失。

### 修法

- 文档 `keydown`：无 Ctrl/Alt/Meta、不在输入框/可编辑区、非输入法组合时，可打印字符（空格除外）→ `focusSearch(key)`；`/` 打开空搜索。
- `focusSearch(seed)`：关历史浮层 → 回首页并切到「全部」→ 把 seed 填入 `#lq` → 重绘 Launcher → 聚焦并把光标放到末尾。
- 顶栏搜索按钮的点击回调改为 `() => focusSearch()`：避免把 PointerEvent 当作 seed 填进输入框（测试中发现）。
- 历史浮层打开时忽略直接输入；命令页提示条改为「输入即搜索」。
- 预览工具 `tools/preview-web-console.js` 改为每次请求重读 `WebConsole.cs`（原来只在启动时读一次，与文档描述不符）。

### 验证

- Edge headless（preview，23 条命令）：
  - 首页输入「演」→ `route=home`、`project=全部`、`q=演`、1 个结果、焦点在 `#lq`；
  - 命令页输入 `d` → 回首页、`q=d`、22 个结果；
  - 命令页输入 `/` → 空搜索、23 个结果；
  - 点击顶栏搜索按钮 → 空搜索、23 个结果、焦点在 `#lq`。
- `dotnet build quickcmdhost\quickcmd-host.csproj -c Release`：0 warning / 0 error。
- `node --check`：页面脚本与预览工具均通过。

## 2026-11-19 · 补充：搜索框常驻 + 跨项目搜索

### 现象

「全部」屏的搜索框时有时无：显示条件写死为 `project === "全部" && route === "home"`。切项目会立刻隐藏；打开命令页时 `openApp` 不重绘 Launcher，要等下一次数据轮询才隐藏，所以观感随机。与「直接输入强制回到全部」叠加后更让人困惑。

### 修法

- `.lsearch` 改为 Launcher 常驻元素（CSS `display:flex`），删除 `.lsearch.on` 与 `renderLauncher` 里的显隐切换。
- 有查询词时跨项目搜索：`let list = q ? cmds() : commandsInScreen()`；结果 tile 的项目名仍标注来源，清空查询回到当前项目屏。
- 直接输入 / `Ctrl+K` / 搜索按钮仍统一回首页「全部」屏并聚焦。

### 验证

- Edge headless（preview）：
  - 首页「全部」：`searchDisplay=flex`，23 个 tile；
  - 项目 `rvvm`：搜索框仍显示，1 个 tile（rvvm）；
  - 在 `rvvm` 输入「演」：跳到全部，1 个结果，项目标签为 `demo`，证明跨项目；
  - wide 命令页：launcher 可见，搜索框仍显示；
  - 700px 命令页：launcher 随左栏隐藏（`leftW=0`），搜索框不可见（预期）。
